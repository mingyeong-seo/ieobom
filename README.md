# 이어봄 (Ieobom)

AI 기반 가족 생활 기록 및 연결 서비스

“오늘의 안부가,
나중엔 가족의 기억이 됩니다.”

---

## 프로젝트 소개

이어봄은  
고령 부모님의 하루를 AI 대화 기반으로 기록하고,
이를 가족에게 “하루 이야기” 형태로 전달하는 서비스입니다.

단순 안부 확인이 아닌,
가족 간 감정 연결 경험을 목표로 합니다.

---

## MVP 핵심 기능

- 부모님 AI 대화
- 하루 스토리 생성
- 보호자 스토리 확인
- 감정 반응 남기기
